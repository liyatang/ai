# 事实与诊断分离，Python 作为单一诊断来源

继续使用 AppKit 原生桌面窗口和 Python 本地采集，避免更换 UI 框架及运行依赖。采集适配器仅提取性能事实，由 Python 纯函数统一判断近期异常、恢复与候选；Swift 只负责生命周期、数据新鲜度兜底和展示。这样可以用相同回归样本验证全部诊断规则，避免 Python 与界面分别解释同一条日志、或从中文文案反推状态。

历史累计不能驱动当前告警，节点名称不能作为身份；不能确认的路由、请求边界或恢复状态必须保留不确定性。观察数据使用独立的 v2 文件，旧版质量历史留在原位置，不导入旧版评级。Python 模块随 App 捆绑安装，使程序与脚本可以一起更新、一起回退；个人配置与缓存继续保存在用户支持目录。
