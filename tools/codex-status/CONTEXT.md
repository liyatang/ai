# Codex 状态

在桌面持续呈现 Codex 额度、连接观察和本机资源的个人状态卡片。

## Language

**后台重试**:
Codex 日志中观察到的连接中断后重试事件，不表示整个任务重新开始，也不保证用户能感知。
_Avoid_: 任务重来、用户可感知断线次数

**当前连接观察**:
近期有效日志和探针支持的连接情况。历史出现过问题与当前仍有问题是不同事实。
_Avoid_: 历史累计就是当前故障、永久健康评级

**重试后继续输出**:
同一任务在重试之后再次出现模型输出的可观察事实，不替其他并发任务证明恢复。
_Avoid_: 全部任务恢复、任务重启成功

**持续异常**:
多次尚无恢复证据的连接重试在连续观察中仍然存在。没有输出本身不是连接故障的证据。
_Avoid_: 思考时间长、无输出超时即网络故障

**ChatGPT 探针延迟**:
本机访问 ChatGPT 轻量端点到收到响应的等待时间，仅描述短请求链路。
_Avoid_: 模型速度、长连接稳定性、代理节点 ping

**选中节点 / 活连接节点**:
选中节点是策略组当前选择的节点；活连接节点是已建立连接实际使用的节点。切换期间两者可能不同。
_Avoid_: 用旧连接覆盖当前选择、把两者都称为当前节点

**观察范围**:
在同一次连续监控及可区分的代理运行环境中积累的证据范围。同名节点不能据此视为同一个服务。
_Avoid_: 节点名称即身份、跨订阅永久评级

**候选节点**:
当前代理环境内具有可用短请求测速证据、供用户手动尝试的其他节点。近期使用记录只是补充依据，不是长期稳定承诺。
_Avoid_: 保证稳定、自动切换、稳定 N 轮

**TUN 已生效**:
代理客户端的 TUN 设置与本机接口及路由观察一致，不等于 Codex 请求必定成功。
_Avoid_: Clash 已打开、网络完全正常

**历史重试**:
在保留时间范围内已经观察到的后台重试事件。它说明过去发生了什么，不驱动当前故障颜色。
_Avoid_: 当前重连次数、完整历史保证
