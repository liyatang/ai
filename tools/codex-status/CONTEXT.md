# Codex 状态

Codex 状态是在桌面持续呈现 Codex 额度、系统负载与连接健康度的个人状态卡片。

## Language

**网络延迟**:
从本机发起 ChatGPT 轻量探针到收到首个响应的等待时间，不代表模型生成耗时。
_Avoid_: Codex 速度、模型延迟

**GPT 节点连接速度**:
通过 mihomo 指定候选节点访问 `https://chatgpt.com/cdn-cgi/trace` 的多次成功率、P50/P90 与最大延迟。测速本身不改变当前 Selector，不调用模型、不消耗额度；香港节点不进入推荐候选。只有用户点击“切换”或“试用”后才修改 Selector。
_Avoid_: 节点 ping、模型生成速度、自动切换

**GPT 稳定性**:
selector 当前选中节点最近 24 小时、至多 20 轮真实 Codex 对话的首连成功、流重连、TLS 异常关闭和连续稳定轮数。稳定性数据的节点名必须与界面选中节点一致；切换后的短暂旧连接断开不计入新节点，只保存性能元数据，不保存对话内容。
_Avoid_: 协议优劣、单次测速、永久节点评级

**选中节点 / 活连接节点**:
选中节点是 GPT selector 的 `now` 值，也是切换与稳定性归属的真源；活连接节点是切换前已建立的 ChatGPT/Codex 连接仍在使用的叶子。两者不同时只提示“旧连接收尾”，不能把旧连接质量记到新节点。
_Avoid_: 用任意旧连接覆盖 selector、把两者都称为当前节点

**稳定节点建议**:
只有当前节点已被真实对话判定为不稳定或不可用时，才建议近期有足够真实稳定样本的其他节点。只有短探针数据的节点称为“候选试用”，不能称为稳定节点；当前稳定或观察中时不建议切换。
_Avoid_: 最快节点、自动优选、当前稳定时的提速建议

**首输出等待**:
Codex 发起一次模型采样请求后，到本地日志出现首个模型输出事件的时间。
_Avoid_: 网络延迟、完整任务耗时

**TUN 有效**:
mihomo 声明开启 TUN，且对应虚拟接口与实际 Fake-IP 路由同时生效的状态。
_Avoid_: Clash 已打开、代理已启动

**诊断可信度**:
现有网络探针、Codex 活动和重试证据对慢因归类的支持强度，不表示服务端提供了精确归因。
_Avoid_: 准确率、服务端结论
